# PDF to Markdown Converter

Convert multiple PDF files to Markdown using Microsoft's MarkItDown in Google Colab.

## Features

- Upload multiple PDF files at once
- Convert all PDFs to Markdown
- Preserve the original PDF filenames
- Automatically create a ZIP file containing all Markdown files
- Works directly in Google Colab

## Requirements

- Google Colab
- Python 3.10+
- Microsoft MarkItDown
